## Social Login

Open Spanner supports dashboard sign-in with email/password and configured OAuth providers. Google and GitHub are built in today, and each provider follows the same variable pattern:

For a closed deployment, create the intended dashboard users first, then restart the API with `OPEN_SPANNER_REGISTRATION_ENABLED=false`. The API rejects new password registrations, OAuth cannot create new users, and the dashboard hides registration. Existing password users, linked OAuth identities, and verified OAuth identities matching an existing user's email can still sign in.

```text
OPEN_SPANNER_<PROVIDER>_OAUTH_ENABLED
OPEN_SPANNER_<PROVIDER>_OAUTH_CLIENT_ID
OPEN_SPANNER_<PROVIDER>_OAUTH_CLIENT_SECRET
OPEN_SPANNER_<PROVIDER>_OAUTH_REDIRECT_URL
```

Use `GOOGLE` or `GITHUB` for the built-in providers. Social login creates the same HttpOnly dashboard session cookies as password login.

Provider buttons are shown only when the provider is enabled and has credentials. To keep credentials configured but hide a provider:

```sh
OPEN_SPANNER_GOOGLE_OAUTH_ENABLED=false
OPEN_SPANNER_GITHUB_OAUTH_ENABLED=true
```

The local callback URLs are:

```text
http://localhost:18081/v1/auth/oauth/google/callback
http://localhost:18081/v1/auth/oauth/github/callback
```

Set explicit redirect URLs when the public browser URL differs from the API listen address:

```sh
OPEN_SPANNER_GOOGLE_OAUTH_REDIRECT_URL=https://open-spanner.example.com/v1/auth/oauth/google/callback
OPEN_SPANNER_GITHUB_OAUTH_REDIRECT_URL=https://open-spanner.example.com/v1/auth/oauth/github/callback
```

For Google, create a Web application OAuth client and add the callback URL under authorized redirect URIs. For GitHub, create an OAuth App and use the matching callback URL.

## Docker Compose Variables

These variables are read by `docker-compose.app.yml` before the Open Spanner container starts:

| Variable | Default | Description |
| --- | --- | --- |
| `OPEN_SPANNER_HTTP_PORT` | `18081` | Host port published for the web dashboard and REST proxy. |
| `OPEN_SPANNER_GRPC_PORT` | `18090` | Host port published for the app container's gRPC listener. |
| `OPEN_SPANNER_INGESTION_*` | service defaults | Passed through to the app container for ingestion size and rate limits. |
| `OPEN_SPANNER_POSTGRES_PASSWORD` | `open_spanner` | Password for the bundled Postgres service and the app connection string. |
| `OPEN_SPANNER_API_DB_MAX_OPEN_CONNS` / `OPEN_SPANNER_API_DB_MAX_IDLE_CONNS` | `20` / `10` | Pool budget passed to the API container. |

## Postgres Example

```sh
OPEN_SPANNER_DB_DRIVER=postgres
OPEN_SPANNER_POSTGRES_DSN=postgres://user:password@db.example.com:5432/open_spanner?sslmode=require
OPEN_SPANNER_DB_MAX_OPEN_CONNS=25
OPEN_SPANNER_DB_MAX_IDLE_CONNS=25
```
