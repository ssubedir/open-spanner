# Open Spanner Web v2

Next.js App Router prototype for the next Open Spanner dashboard. Source files live under `src/`, routes are defined by folders in `src/app/`, and reusable shadcn-style primitives live in `src/components/ui/`.

```sh
npm install
npm run dev
```

Open [http://localhost:3000/overview](http://localhost:3000/overview).

## Checks

```sh
npm run lint
npm run typecheck
npm run build
npm audit
```
